### ReadyCube Buildings Website (Internship Project)
> A modern corporate website with a custom admin panel that lets the client manage site content without touching code.

- Built the frontend with **React, TypeScript, Vite, Tailwind CSS and shadcn/ui**, based on a defined brand palette and a responsive UI specification.
- Architected a **3-tier MERN** system: React client, single Express API and MongoDB.
- Implemented secure admin access using **JWT cookie authentication**, idle-timeout renewal, account lockout, CSRF protection and global rate limiting.
- Provided an admin API for content and media management, plus storage and review of customer quote and contact submissions.
