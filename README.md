- RESTful API built with **Node.js, Express and Sequelize**, backed by **Neon (serverless PostgreSQL)**
- Responsive **React** dashboard for managing tasks
- Automated tests and a **GitHub Actions CI** pipeline; preparing deployment on **AWS**
- **Tech:** React · Node.js · Express · Sequelize · PostgreSQL · GitHub Actions · AWS
- 🔗 [View repository](https://github.com/KMDS21/Task-Manager-Web-App)

### 🌱 Smart Water Management for Sustainable Agriculture
An IoT-based mobile application for efficient agricultural water management.
- Live monitoring and real-time data tracking with **Flutter** and **Firebase**
- Supports sustainable irrigation and smarter, data-driven decisions
- **Tech:** Flutter · Firebase · Arduino · IoT

- **Tech:** React · TypeScript · Tailwind · Node.js · Express · MongoDB
